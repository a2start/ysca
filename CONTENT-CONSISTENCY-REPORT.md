# YSCA content consistency report

## Implemented and retained corrections

| Topic | Previous inconsistency | Current approach |
| --- | --- | --- |
| Programme naming | Mixed U-group labels and age ranges. | Uses Foundation Cricket (ages 6–10), Junior Development (ages 11–14), and Senior Performance (ages 15–19). |
| Trial calls to action | “Free Trial”, “Free Net Trial”, one-day and one-hour promises appeared without verified terms. | Canonical pages use enquiry-led trial wording. |
| Shared footer | Repeated “real match exposure” and “experienced coaches” claims appeared across templates. | Uses neutral wording that directs visitors to confirm current programmes, batches and facilities. |
| Location | Previous Delta II references and map data were inaccurate. | Uses FFW9+CM, Malakpur, Uttar Pradesh, India and confirmed coordinates. |
| Facilities / hostel | Fixed counts, meals, supervision and equipment were contradictory or unsupported. | Uses current-availability and confirmation wording. |
| Coaches | Certifications, affiliations, achievements and experience totals were unsupported or conflicting. | Canonical profiles use neutral, role-led wording and request confirmation for qualifications. |
| Social profiles | Generic network homepages were presented as academy destinations. | Removed until official URLs are supplied. |

## Owner confirmation still required

The academy must confirm current fees, trial terms, schedules, coach credentials, facilities/equipment, hostel inclusions, admissions hours, official social profiles and any selection or achievement claims before those details are published. See [SEO-FACT-VERIFICATION.md](SEO-FACT-VERIFICATION.md).
